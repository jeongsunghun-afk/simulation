02_Leg 실기 브링업 — 모터에서 모델까지

아래층부터 격리 검증하고 쌓는다. 오차는 위로 누적되므로 — 모터 부호 하나가 틀리면 다리·모델·보행 검증이 전부 해석 불가가 된다. 각 층을 못 박은 뒤에야 다음 층으로 올라간다.

P0
안전·센서
리밋·부호·지연
P1
액추에이터
위치·토크·ID
P2
단일 다리
J·G·M,C → F
P3
전체 로봇
추정·서기·보행

흐름은 단방향 — 각 단계가 다음 단계의 전제. 되돌아가 디버그하지 않도록 층마다 합격 기준으로 못 박는다.

⚠ 백래쉬를 가장 먼저

영점교차 히스테리시스가 위치·토크·모델을 모두 오염시킨다. 액추에이터 ID의 첫 항목으로 검출.

◆ 모델 먼저, F는 나중

F는 τ = Mq̈ + h − JᵀF로 모델을 통해 실현된다. 모델(J·G·M,C)이 틀리면 F를 디버그할 수 없다 — 순서를 뒤집어야.

✔ F센서는 불요

F는 WBC QP의 결정변수(계산값)이지 측정값이 아니다. 포스플레이트는 검증에만 임시 사용, 제어엔 없음.

PHASE 0

전원 인가 전

준비 · 빠지면 위험
  • ◦
    안전 인터록
    토크·속도·위치 리밋 + e-stop 배선 — 어떤 통전 시험보다 먼저.
  • ◦
    센서 sanity
    엔코더 방향·영점·단위(rad) · 전류→토크상수 k_t · IMU 부호. 부호 오류는 상위 전부를 무너뜨린다.
  • ◦
    통신 지연 측정
    지령→반영 round-trip 실측. 우리 PACE 식별 = 8.39 ms.
PHASE 1

단일 액추에이터 벤치

모터 격리
  • ①
    위치제어 (PD)
    스텝응답·대역폭·정상오차·부호.
    합격 = 지령 위치를 추종, 정상오차 소, 발진 없음 (저수준 루프·엔코더 검증)
  • ②
    토크제어
    지령 τ vs 실측(전류)·선형성·데드존.
    합격 = τ–실측 선형 일치, k_t 확정 (전류루프 검증)
  • ③
    액추에이터 파라미터 ID ①② 루프로 가진
    아래 순서로 식별 — 백래쉬 먼저.
    • ▸ 백래쉬 (★가장 먼저): 반전/영점교차 히스테리시스
    • ▸ τ_c(쿨롱)·b(점성): 등속 스윕 → τ–v 절편·기울기
    • ▸ Rotor_I(반사관성): 무부하 가속 → τ–a
    • ▸ 지연·대역: 스텝/처프
    • ▸ 기어비: 지령각 vs 실제각 비
    = 우리 PACE CMA-ES 적합 · Rotor_I 7.327e-4 · per-axis b · τ_c · 지연 8.39 ms
PHASE 2

단일 다리 조립

★ 모델 → F 순서
  • ④
    J · 기구학
    관절각 → 발위치(외부측정/모캡) FK 일치·부호·스케일·관절리밋 + calf-foot 커플(평행사변형, couple_clamp).
    합격 = FK 오차 소, 커플 제약 실측 확인
  • ⑤
    G · 중력
    각 자세에서 τ = G(q)만 인가 → 떠 있나(float).
    합격 = 최소 드리프트로 홀드 (링크 질량·CoM 검증 — 힘 안 재고)
  • ⑥
    M, C · 역동역학
    τ_ff = Mq̈ + Cq̇ + G 궤적추종(피드백 낮게). C는 빠르게 흔들 때 드러남.
    합격 = 낮은 피드백으로도 추종 (강체모델 검증)
  • ⑦
    F · 접촉력 (종합시험)
    발을 저울/포스플레이트에 → 지령 λ vs 실측 힘 일치? + 마찰(예측 μ에서 슬립?).
    합격 = 지령 F 실현 + 예측 μ 부합 → 모델 통합 검증 완료
    ◆ 포스플레이트는 검증용 임시만 — 제어엔 F센서 불요(QP가 계산)
PHASE 3

전체 로봇

통합·폐루프
  • ⑧
    상태추정
    접촉 KF·base 속도 vs 모캡. proprio(엔코더·IMU·전류)만으로 추정 — F센서 없이.
  • ⑨
    서기 / 균형
    WBC stance 홀드. 자세 유지·발바닥 접지.
  • ⑩
    보행 / 외란
    게이트(walk·trot·run)·푸시 복구. 운용속도는 여유 두고(관절부하).
제안 순서
위치 → 토크 → (Rotor_I·τ_c·b·백래쉬) → 다리조립 → F → 모델(M,C,G,J)
정정판
P0 안전·센서·지연 → 위치 → 토크 → ID(백래쉬 먼저·τ_c·b·Rotor_I·지연·기어) → 다리조립 → J·G·M,C(모델) → F(종합) → 추정 → 서기 → 보행
정정 요약 — ① 앞에 Phase 0(안전 리밋·센서 부호/영점·통신지연 8.39ms) 추가. ② F ↔ 모델 순서 뒤집기: F는 τ=Mq̈+h−JᵀF로 모델을 통해 실현되니, 모델 조각(J·G·M,C)을 먼저 못 박고 F를 종합시험으로. ③ 백래쉬는 액추에이터 ID 중 가장 먼저(하위 전부 오염원). ④ ID 전체 = 우리 PACE CMA-ES 절차. ⑤ 다리 레벨에 calf-foot 커플 확인. F 검증엔 포스플레이트를 임시로 쓰되 제어엔 F센서 불요(F는 WBC QP 결정변수).
