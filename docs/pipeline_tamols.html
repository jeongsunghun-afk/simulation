TAMOLS 지형 계획층 — A 실행스택 위에

TAMOLS(Terrain-Aware Motion Optimization, Jenelten 2022)는 컨트롤러가 아니라 TO(계획)층 — base pose(위치·자세)+발판을 GIAC 안정제약으로 co-optimize. A 파이프라인의 ③발배치·④x_ref 자리에 끼어들어, 그 아래 MPC→WBIC 실행스택은 그대로 재사용한다.
본 문서=TAMOLS가 A 위 어디에 어떻게 붙나 + TAMOLS 문제정의 + 협조 실증·한계. 실행층(MPC/WBIC) 상세는 pipeline_a.html.

★GIAC 유도 & 성립조건 (2026-09 정리) — GIAC = 동역학+마찰콘에서 힘 f를 소거한 것. 볼록성 덕에 개별 발 마찰콘의 합력 조건이 CoM 가속으로 접힘: 17a (μ·aG_z)²≥aG_x²+aG_y² = 마찰콘의 CoM 버전, 17b m·det(pij,pB−pi,aG)−pij·L˙≥0 = 각운동량의 지지영역 버전. 힘을 안 풀어 QP가 가벼움(<20ms).
대가 = 예측 base 부재: base 스플라인은 운동학 계획이라 "지금 넘어짐"을 못 봄 → pure-online RSL 추종은 정지조차 못함. 성립하려면 준정적(a≈0) + walk(3점지지=GIAC 유효). trot(2점)은 느려도 선분지지라 대각축 퇴화로 실패.
τ는 TAMOLS가 안 냄: 힘도 τ도 없음. 추종기(WBC)가 계획을 참조로 [q¨,f] 재계산 → τ=Mq¨+h−Jᵀf. 강건도 순서: RSL(순수추종) < injection(A 예측층 빌림·flat견고·gap실패·마진얇음) < D1(통합 NMPC·예측 내장)이 종착점.
