상태추정 (sim2real) — GT는 개발용, EST 성공이 배포 기준
실기엔 절대위치 센서가 없으므로 제어기는 추정 상태로 돌아야 진짜 sim2real이다. 그래서 GT=궤적·제어기 검증용 옵션, EST(폐루프) 성공을 최종 배포 기준으로 삼는다(EST_CTRL). 뷰어 '모니터 표시(viz)' 체크박스=추정 고스트(초록 GT vs 주황 EST) 시각 비교.
추정기(state_estimator.hpp, leg-odometry) — IMU(자세·각속도) + 관절 엔코더(q,q˙) + 발 접촉만 사용, 절대위치 미사용(실기 동일):
  • 자세=IMU 직접 · 각속도=자이로 직접.
  • 위치 z=접촉발 기구학(평지 ground_z 기준, base_z=ground−mean(발 상대z)) → 드리프트 0.
  • 위치 xy=stance-anchored(접촉발을 월드 앵커로 고정 → base=mean(anchor−R·pfb)) + 미끄럼 아웃라이어 재앵커. 앵커가 ZUPT를 대체해 앉기/서기(몸 상하·CoM gather)서도 드리프트 없이 추종.
  • 속도=접촉발 zero-velocity 평균+저역통과, 정적/기립 모드=속도 ZUPT(fold 미끄럼 거짓속도 제어 교란 차단).
검증: 개루프 고스트 오차 sit↔stand 반복 1.4m→4cm(z 1.7cm), 보행 6cm.

② 표준 접촉기반 선형 KF(estimate_kf(), EST_KF=1 — MIT Cheetah·Bledt 2018) — IMU 가속도 융합 채택: 상태 [p, v, 발4위치] 18차, 가속도로 예측(접촉 무관 고속) + 접촉발 상대위치·정지속도·지면z로 보정(칼만이득이 공분산으로 자동 가중, swing발=공분산 거대화로 무시). 가속도 예측이 접촉불량 구간(기립 fold·점프 flight)을 이어줘 속도가 안 튀는 게 핵심 — 폐루프 반복 기립을 안정화(2사이클 전복 → 6사이클 tilt 4°). 자세는 IMU 직접(필터 밖).

InEKF(Hartley 2020, Lie군 자세정합)는 이 선형 KF의 일반화이나 미채택 — 우리는 IMU 자세를 직접 써 정확하고(자세를 필터로 감싸면 오히려 지연), 관측불가 모드(절대 xy·yaw 드리프트)는 어떤 필터도 못 잡아 실익이 없다. InEKF 이점(자세 일관성)은 공격적 기동·자이로 바이어스에서 나오므로 실기서 필요시 격상. 절대 xy·yaw는 exteroception(VoxelSLAM2, nav)로 보정.
기동별 배포 방식 — leg-odom 전제(디딘 발=고정)가 지켜지느냐
보행(wbic_track)=발 주기접촉=정상영역 → EST 폐루프(KF). · 기립(getup)=fold 미끄럼+base 대이동=전제 깨짐 → rise는 wbic 균형 필수(pure 관절-PD는 GT도 전복), wbic 참조를 절대 xy 비의존(rise=현재 CoM 상대추종)+속도는 KF로 확보. · 점프(jump)=이미 발사점 상대(jump_launch_com), flight는 IMU 가속 적분. 공통: 기립·점프는 절대 base 위치 비의존(피드포워드+자기수용감각), 절대량은 균형에 불필요.

폐루프(EST_CTRL) 검증 — 선형 KF로 충분: 전진+허리조향 선회가 GT와 yaw·궤적 일치(yaw −119° 동일, tilt<1°, falls=0). 반복 기립 6사이클 falls=0(tilt 4°), 단발 점프 착지 falls=0.

현실 노이즈·지연 강건성(ENC/GYRO/ACC 노이즈 + 3ms 지연): 추정기는 노이즈에 강건(노이즈만이면 보행·선회·기립 falls=0). · 선회=노이즈+지연 복합서 전복→KF_QV 0.5(가속도계 노이즈 반영=접촉측정 신뢰↑)로 해결(114°→0.3°, 클린 무회귀)→기본값. · 기립=지연 단독 2ms로도 실패(추정 아닌 제어 지연 문제), 섬세한 wbic 균형상승이 작동지연에 민감 → 별도 컨트롤러 강건화 과제. 실기 잔여: 자이로 바이어스 절대 heading 표류(InEKF+exteroception) + 기립 지연예산.

MPC 2 · 솔버가 푸는 문제 — Convex SRBD (condensed QP)

단일강체(SRBD) 선형·볼록·시변(LTV). 현재 자세 R로 매 호출 선형화. 상태를 소거한 condensed QP(결정변수=GRF만).

상태 & 결정변수

x ∈ R¹³ = [ roll, pitch, yaw,  px,py,pz,  ωx,ωy,ωz,  vx,vy,vz,  g ]  (ω=world, g=−9.81 증강)
U = [ λ0 … λN−1 ] ∈ RN·12  각 스텝 λ = 4발 × 3(world GRF), N=14 → 168차원. QP는 첫 스텝만 사용

연속 동역학 (CoM 기준)

Θ˙ = Rz(yaw)T·ω    p˙ = v    ω˙ = Iw−1 Σi ri×λi    v˙ = (1/m) Σi λi + g

Iw = R·Ibody·RT (현재자세 회전) · ri = 발i − CoM · 이산화 xk+1=Adxk+Bd,kuk (Ad=I+DT·Ac, 접촉 발만 B에 기여). condensed: X = Aqx0 + BqU.

비용

minU  Σk (xk−xref)T Q (xk−xref)  +  ukT R uk
Q = diag( 200,200,100,  0,0,200,  0,0,1,  10,10,1,  0 )  R = 10−6

자세(roll/pitch/yaw)·높이 z·ωz·수평속도 중시. xy 위치·수직속도=free(0). H=2(BqTQˉBq)+2Rˉ, diag+=1e−8(PD 보장).

제약

  • stance 발 (부등식 Gu≤h): 마찰추 |λx|≤μλz, |λy|≤μλz · λz ≥ LAMZ_MIN(1) · λz ≤ LAMZ_MAX(2mg)
  • swing 발 (등식 Au=b): λi = 0
  • μ = MU · MU_MARGIN = 0.6 × 0.707 = 0.424

솔버: eiquadprog (active-set). 실패 시 fallback = 접촉발 균등 수직력 mg/ns. 출력: lam[4×3] 첫 스텝 GRF(world).

지형 Online foothold opt. (footScore/selectFoot)

A의 지형 크로싱 = elevation-map footScore로 발판 선택 + base MPC 별도(그림 "Online foothold opt.", Jenelten 2020 계보, 폐루프). 연속 지형은 반응형이나 A 단독은 불연속 험지(갭/징검다리) 취약(~0.10~0.15m 갭 한계). ★TAMOLS 계획층 주입(pipeline_tamols): A gait클럭에 TAMOLS base·발판 주입(TAM_BASE=base-발판 협조) → 지형 크로싱(hsteps tilt<1.2°·dsteps2 갭+높이 3.4°·falls=0). 단 injection=짜깁기라 마진 얇음 → 강건=D1 포팅(OCS2 NMPC) 또는 RL(DTC). 계보·상한=A·B·C·D1 비교·TOWR 리포트·메모리 perceptive-nav-tamols.
