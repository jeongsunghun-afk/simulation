가정을 험지로 정의한다 —
쇼파를 오르고, 어질러진 바닥을 걷고, 코너를 접어 도는 로봇

로봇청소기는 평지 2D만 다니고, 휴머노이드는 가정에 과잉·고가입니다. 가정의 실제 지형 — 높고 푹 빠지는 쇼파·침대, 장난감이 널린 바닥, 가구 사이 좁은 코너, 날아오는 돌발 상황 — 은 비어 있는 문제이며, 이를 푸는 열쇠는 기구 4요소(좁은 몸폭 · 3-link 다리 · 목 · 허리)와, 검증된 네 제어 계보(CI-MPC · DTC · APT · AMP)를 참조해 설계하는 단일 통합 제어기입니다.

01 형태가 곧 기능 — 네 개의 형태가 네 개의 벽을 연다
측면 개략도 — 뒷다리 도약 자세로 쇼파에 접근, 목 카메라가 터치다운 지점 직시, 허리 분리 조향. 좌상단 톱뷰: 좁은 몸폭으로 가구 사이 통과.

① 3-link 다리 추진 · 다중접촉

긴 유효 스트로크로 점프·등반 추진력을 확보해 쇼파·침대 높이를 도약으로 넘고, 푹 빠지는 표면의 출렁임을 받아낼 깊은 자세 회복 여유를 가지며, 무릎·정강이까지 접촉면으로 쓰는 다중접촉·불연속·미끄럼 대응의 기구학적 캔버스가 됩니다.

② 목 vision/depth 사각 제거

디딤발 발밑 사각지대를 직시 — 터치다운 직전 지형을 확인해 지도 누적이 만드는 드리프트·가림·지연 의존을 원천 우회. 능동 시선으로 다음 발판·날아오는 물체를 주시하는 빠른 대응의 감각 기반.

③ 허리 yaw 협소 선회

몸을 접어 회전반경을 축소, 자동차식 조향으로 좁은 코너를 돕니다. 이동 방향과 상체(시선·대응) 방향의 분리로 민첩성을 더합니다.

④ 좁은 몸폭 통로 통과

가구 사이·문틈 같은 좁은 통로를 몸 자체로 지나갑니다. 폭이 좁아지면 옆으로 버티는 여유도 함께 줄어드는데, 이는 발배치 균형 제어가 감당합니다 — 제어가 받쳐줘야 가능한 설계입니다.

02 문제 → 기구 → 제어 — 빈 칸 없는 매핑
가정환경의 벽담당 기구통합 제어기가 푸는 방식 (참조 계보)
높고 푹 빠지는 쇼파·침대→ 3-link 다리 오르기 — RL 정책이 직접 수행: 도약·등반·무릎짚기를 상황에 맞게 실행하며, 그 스킬은 접촉을 스스로 발견하는 교사 궤적(CI-MPC 계보)으로부터 사전학습·훈련됨. 버티기 — 매트리스는 누른 만큼 되밀어내는 탄성 표면이라 로봇과 함께 출렁이고 한 발의 하중이 다른 발의 접촉을 기울임: 발배치 균형 + 표면 물성(강성·감쇠) 랜덤화 학습으로 대응 — 이 미션에서 가장 어려운 제어 문제
장난감·케이블 난잡 바닥→ 목 + 다리 정밀 발판 국면에서 계획 발판을 정책의 입력으로 받아 cm급 정밀도로 강건 실행(목표 발판 대비 착지 오차 수 cm — 검증 계보 실증 ~3 cm, DTC), 목 시야가 계획-현실 간극을 봉합
좁은 코너·가구 사이·문틈→ 허리 + 좁은 몸폭 좁은 몸폭이 통과 가능한 통로 폭 자체를 낮추고, 허리 yaw+lean 조향(자체 스택 검증 계층 확장)이 그 폭 안에서의 선회를 담당 — 줄어든 측방 여유는 발배치 균형이 흡수
돌발 상황 (낙하물·아이·반려동물)→ 목 + 전신 단일 정책이 잠재 스킬 공간에서 걷기↔달리기↔도약을 자율 전환 (APT 계보 — 순간 6 m/s 실증, Sci. Robotics 2026)
03 하나의 제어기 — 모델기반 레퍼런스 생성 → RL(PPO)이 소화하는 3계층 분담

오프라인 TO 하이브리드 ← DTC (TOWR+RL)

오프라인 궤적최적화(TOWR)가 지형 조건부 발판·타이밍 레퍼런스를 만들고 RL이 이를 추종 — cm급 정밀과 RL 강건성을 한 정책에 결합하는 하이브리드.

보유: 배포 스택(1.85 m/s)·지형계획기·지형맵 완비

모델기반 레퍼런스 (접촉창발) ← CI-MPC

MuJoCo 리타게팅 → CI-MPC → 레퍼런스: 리타게팅이 로봇 형상 운동학 시드를 주고, CI-MPC(상보성 접촉)가 접촉·동역학·토크를 채워 접촉창발 스킬(도약·다중접촉·soft) 레퍼런스 생성 — 모델기반 액션에 강해 RL의 먹이(APT 잠재공간·AMP 판별기).

보유: CI-MPC 자체 구현 2종 · MuJoCo 리타게팅 파이프라인

RL 학습·배포 ← PPO (RMA·AMP·APT)

위 레퍼런스를 소화해 단일 정책 하나 산출 — APT(행동공간·잠재 스킬+토크 디코더) · AMP(스타일 보상) · RMA(특권→실센서 적응/증류). 배포는 추론만 100 Hz.

보유: TO 데이터 공장 — 스킬 사전학습 입력으로 즉시 전용
✔ 파이프라인 정합모델기반 레퍼런스 계층(MuJoCo 리타게팅·CI-MPC·TOWR)은 레퍼런스를 공급만 — 배포물엔 솔버 없이 정책 가중치로 각인(APT). RL 축(APT·AMP·RMA)은 직교라 한 정책에 동시 탑재(선례 다수).
✔ 데이터 호환교사 계층(CI-MPC·TOWR·2D TO)이 전신 상태+토크 궤적 공급 — 스킬 사전학습 입력과 일치(2D 교사의 관절 공백은 CI-MPC 전신 3D로 보완).
△ M1 검증 2항추종·과제·스타일 보상의 가중 균형(경합 시 저하 사례 — 국면별 게이팅) · 스킬 리듬↔계획 스케줄 타이밍 정합.

가정환경은 기존 제품군이 물리적으로 진입 불가한 시장이며, 핵심 제어 기술 계보가 최근 24개월 내 모두 실기 성립했고 그 구현 자산을 우리가 이미 보유하고 있습니다. 기구 4요소(좁은 몸폭·3-link 다리·목·허리)를 반영한 차기 기체 설계와, 네 계보를 엮은 단일 통합 제어기의 M1 실증 착수를 제안합니다.

행동·토크 합성 APT Methods 원식

τinput = τdec(alatent) + kp (qdefault − q + 0.2 aaux) − kd q˙(kp=80, kd=2)
  • 사전학습 FF 토크 + RL 피드백 하이브리드 — aaux가 3D·미지 지형·데이터 공백 보정
  • alatent에 KL(𝒩(0,I)) 소프트 정규화 + 탐색 보너스 감쇠

관측·보상·커리큘럼

  • 보상 3항: rtask + rtrack(정밀 국면 한정 게이팅) + rstyle(AMP 판별기, 𝓜=S0 전체) — ★수제 스타일 항과 병용 금지(경합 시 성능 저하 실측)

왜 교사는 제어기 구성요소가 아닌가

  • CI-MPC·TOWR·2D TO는 훈련 이전 단계에만 존재 — 궤적을 만들고, TVAE 디코더와 AMP 판별기 데이터셋으로 소비된 뒤 폐기. 배포 스택에는 그 지식이 정책 가중치로 각인되어 남을 뿐 솔버는 없음
  • 3원천 분업: 2D TO=평지 게이트 대량(9만 궤적/게이트) · CI-MPC=접촉 창발 스킬(도약·다중접촉·soft — 유일 공급원) · TOWR=지형 조건부 발판+타이밍
  • 승격 경로 1건: CI-MPC가 C++ 40 Hz 실시간화에 성공하면 런타임 발판·타이밍 생성기(DTC 채널) 자리로 승격 가능 — 그때도 제어기의 축이 아니라 채널의 공급원

훈련 증분 순서 · r_track 게이팅 설계

  • H0: APT+PPO+RMA만(참조·AMP 없음) — 평지~일반 험지 기본기 → H1: DTC 채널 추가(정밀 지형 커리큘럼 진입) → H2: 모션 품질 문제 실측 시 AMP 항 추가(동시에 수제 스타일 항 제거)
  • 게이팅 규칙(안): r_track은 참조가 존재하는 스텝에만 활성 + 참조 드롭아웃(에피소드별 확률적 결측)으로 자율 모드 동시 학습 — 게이팅 신호 자체를 관측에 노출해 정책이 모드를 인지
  • 타이밍 정합 완화: 교사 데이터에 가변 stance(TOWR Tg 0.4~0.8·CI 창발 타이밍) 포함 → 디코더가 처음부터 가변 리듬을 학습, 계획 cs와의 충돌 면적 축소. 실패 시 후퇴선 = cs 제외·p_tgt만 전달

  • margin = 발반경 + σ_place(발배치 불확실성). edgeSDF 지배(갭·굴러떨어짐 회피)·slope 보조·roughness 저비중.
  • 게이트 무관 — walk/trot/run/stairs 전부 적용. 불연속 지형은 정밀배치 walk/stairs가 본선.

하위 추종기 — TSID vs WBIC

  • WBIC(wbic_track·w_lam10)=MPC GRF λ* 추종 · TSID(wbic_jump·λ자유)=모션 추종(TAMOLS 트래커 원형) · wbic_stance=정적 TSID.
  • 가름: 상위(TAMOLS 등)가 정밀 per-foot GRF를 내는가 — 있으면 WBIC, 없으면 TSID(기본). 단일 QP + w_lam 스위치로 겸용.

통합 난점 = 프레임·타이밍 (배선 아님)

  • ①odom 프레임: 맵·발판을 로봇중심/odom서 쿼리 → 절대드리프트해도 국소 상대기하 정확(leg-odom·ZUPT 직결).
  • ②비동기: 맵 수십Hz vs 제어 1kHz → 더블버퍼+atomic 스왑(never-block). ③latency: 맵 지연↔상태 타임스탬프 정합(발판 어긋남 방지).
★대체 표기 — 구 nav 설계의 TRG-planner → TAMOLS → WBC 3층은 현재 STGN+Nav2(전역/로컬 항법, F2·F3) + RL(험지 크로싱, 2026-07-15 피벗 확정)로 대체됨. 살아있는 건 위 4접점(TerrainMap 심·점접촉 footScore·TSID/WBIC 스위치·프레임/타이밍)뿐. TAMOLS 축소모델의 매력(B/C full-dyn ill-conditioning 우회)은 RL 교사(DTC/TOWR) 맥락으로 이어짐.
